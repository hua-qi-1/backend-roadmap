## 2. 市场现实（先看清，再定计划）

- 国内后端岗位：**Java 占大头（60%+）**，其次 Go（字节/腾讯/美团部分团队）、C++（基础架构/游戏）。你已经在学 Java → **就走 Java 后端，别中途换语言**。
- 岗位 JD 里的高频词，就是你的学习清单：`Java` `Spring Boot` `MySQL` `Redis` `消息队列` `Linux` `Docker` `并发` `JVM` `微服务`。
- 面试 = **四件套**：① 八股（基础八股文）② 算法手撕 ③ 项目深挖 ④ 简历与软素质。四样缺一不可，别只刷八股。
- **时间线很关键**：大厂暑期实习（转正实习）通常 **3 月开招、4–5 月笔试面试、5–6 月发 offer、7 月入职、8–9 月转正答辩**。所以你必须在 **2027 年 2 月底前** 把 Java + Spring + MySQL + Redis + 一个项目跑通，3 月才能有东西可投。
- 学校是双一流但非 985/211 顶尖 → **项目深度 + 实习经历**是你最大的翻盘点。**如果能在大三上或寒假先拿到一段日常实习（哪怕小公司、远程），暑期实习的竞争力会明显上一个台阶。**

## 3. 学习内容清单

### 第一优先级：面试必问，占 70% 精力

#### 3.1 Java SE（2 周，10 月下旬）
- 集合框架：`ArrayList` vs `LinkedList`、`HashMap`（**源码级**：哈希扰动、扩容、红黑树化、为什么容量是 2 的幂）、`ConcurrentHashMap`、`LinkedHashMap`
- 泛型：类型擦除、通配符 `? extends / ? super`
- 异常体系、try-with-resources
- IO / NIO：字节流字符流、`Buffer`/`Channel`/`Selector`
- 反射、注解、动态代理
- Lambda + Stream API（集合处理必用）
- Object 方法：`equals`/`hashCode`/`toString` 约定

#### 3.2 并发编程（3 周，11 月，**最硬的一块**）
- 线程生命周期、`Thread`/`Runnable`/`Callable`/`Future`
- `synchronized`（锁升级：偏向→轻量→重量）、`volatile`（可见性/禁止重排）
- **JMM**：原子性、可见性、有序性、happens-before
- CAS、`AtomicInteger`、ABA 问题
- **AQS** 原理、`ReentrantLock`、`ReadWriteLock`、`Condition`
- **线程池**：7 个核心参数、4 种拒绝策略、`submit` vs `execute`、线程数怎么定
- `ThreadLocal`（内存泄漏原因）、`CountDownLatch`/`Semaphore`/`CyclicBarrier`
- 死锁的四个必要条件与排查

#### 3.3 JVM（1.5 周，11 月底）
- 内存区域（堆/栈/方法区/程序计数器/本地方法栈）、对象创建与内存布局
- 垃圾回收：可达性分析、分代收集、GC 算法、**CMS / G1 / ZGC** 区别与适用场景
- 类加载机制、双亲委派、打破双亲委派的场景（Tomcat/SPI）
- 常用参数（`-Xms -Xmx -Xmn -XX:MetaspaceSize`）、`jps/jstack/jmap/jstat`、OOM 与 CPU 100% 排查流程

#### 3.4 MySQL（3 周，12 月，**面试重灾区**）
- 索引：B+ 树为什么比 B 树/哈希好、聚簇索引 vs 二级索引、回表、覆盖索引
- **最左前缀原则**、索引失效的 8 种情况、`explain` 每个字段怎么看
- 事务：ACID、四种隔离级别、脏读/不可重复读/幻读
- **MVCC**：undo log、read view、版本链（必须能画图讲）
- 锁：行锁/表锁/间隙锁/临键锁、意向锁、死锁排查
- 日志：redo log / undo log / binlog，两阶段提交
- 优化：慢查询日志、`show profile`、分页优化、连接池（HikariCP）
- 进阶概念：分库分表（ShardingSphere）、主从复制、读写分离（知道思路即可）

#### 3.5 Redis（2 周，1 月）
- 5 大数据结构 + 底层编码（SDS、ziplist、quicklist、skiplist、hashtable）
- 典型用法：缓存、计数器、排行榜（zset）、分布式锁、Session 共享、消息队列（Stream）
- 持久化：RDB vs AOF、混合持久化
- 过期策略（惰性 + 定期）、内存淘汰 8 种策略
- **缓存三大问题**：穿透（布隆过滤器/空值缓存）、击穿（互斥锁/逻辑过期）、雪崩（过期时间打散/多级缓存）
- 分布式锁：`SETNX + EXPIRE` 的问题、Lua 原子性、Redisson 看门狗、Redlock 争议
- 高可用：主从、哨兵、Cluster 分片

#### 3.6 计算机网络 + 操作系统（2 周，1 月）
- HTTP/1.1 2.0 3.0、HTTPS 握手、对称/非对称加密、证书
- TCP：三次握手/四次挥手、为什么是三次、TIME_WAIT、粘包拆包、滑动窗口、拥塞控制
- DNS 解析、CDN、Cookie/Session/Token/JWT
- 进程 vs 线程 vs 协程、进程通信、**IO 多路复用（select/poll/epoll，epoll 为什么快）**、零拷贝
- 死锁、内存管理、页面置换

#### 3.7 数据结构与算法（贯穿全程，每天 2 题）
- 题型顺序：数组/双指针 → 链表 → 哈希 → 栈队列 → 二叉树 → 回溯 → 贪心 → 动态规划 → 图 → 排序/二分
- 目标题量：**3 月前 150 题**，面试前累计 **200–250 题**（LeetCode 热题 100 + 剑指 Offer + 高频企业题）
- 要求：每题能在 15 分钟内写出无 bug 的代码，并能说清时间/空间复杂度

### 第二优先级：加分项，中厂必问、大厂常问

#### 3.8 Spring 全家桶（3 周，2 月）
- **Spring**：IoC/DI 原理、Bean 生命周期与作用域、**循环依赖三级缓存**、AOP（JDK 动态代理 vs CGLIB）、事务传播行为（7 种）、声明式事务失效场景
- **Spring MVC**：一次请求的完整流程（DispatcherServlet → HandlerMapping → HandlerAdapter → ViewResolver）
- **Spring Boot**：自动配置原理（`@SpringBootApplication` 三个注解、`spring.factories`/`AutoConfiguration.imports`）、starter 机制、配置文件优先级、拦截器 vs 过滤器、全局异常处理、参数校验
- **MyBatis / MyBatis-Plus**：`#{}` vs `${}`、一级/二级缓存、动态 SQL、分页插件

#### 3.9 中间件与分布式（3 月，边做项目边学）
- 消息队列：Kafka/RocketMQ 架构、为什么快（顺序写 + 零拷贝 + 批量）、顺序消息、重复消费与幂等、事务消息、消息积压怎么办
- 分布式：CAP/BASE、分布式 ID（雪花算法）、限流（令牌桶/漏桶/滑动窗口）、熔断降级（Sentinel）、注册中心（Nacos）、RPC（Dubbo 调用流程）
- 分布式事务：2PC/TCC/本地消息表/Seata（知道思路，能讲清取舍）

#### 3.10 工程能力
- Linux：`grep/awk/sed/find/tail`、`top/vmstat/iostat/free`、`netstat/ss`、日志排查、Shell 脚本
- Docker：镜像/容器/仓库、Dockerfile 编写、`docker-compose` 一键起 MySQL+Redis
- Maven：依赖管理、生命周期、多模块
- 日志：SLF4J + Logback、日志级别与脱敏
- 接口文档：Swagger / Knife4j
- 单元测试：JUnit 5 + Mockito

### 第三优先级：差异化（有余力再碰，别提前学）
分布式事务源码、Elasticsearch、Netty、Spring 源码、JVM 调优实战、Kubernetes

## 5. 项目怎么选（这是简历的命）

**原则：宁可一个项目讲到 30 分钟，也不要五个项目每个讲 3 分钟。** 不要直接抄 GitHub 上的完整项目——面试官一问"为什么这么设计"就露馅。

### 项目一（3 月前完成）：高并发秒杀系统 ★推荐
- 技术栈：Spring Boot + MyBatis-Plus + MySQL + Redis + RocketMQ（或 RabbitMQ）+ JMeter
- 必须做出来的点：
  - Redis 预减库存 + **Lua 脚本保证原子性**
  - 消息队列异步下单（削峰）
  - 接口限流（令牌桶）+ 验证码/防刷
  - 库存超卖问题（乐观锁 / 唯一索引兜底）
  - JMeter 压测：**记录 QPS、P99 延迟、优化前后对比**
- 能讲的问题：超卖怎么防？缓存和数据库怎么保证一致？MQ 消息丢了怎么办？重复消费怎么幂等？

### 项目二（4–5 月）：二选一
- **短链系统**：发号器（雪花/号段）、布隆过滤器防穿透、Redis 缓存、301 vs 302、统计点击（HyperLogLog）
- **IM 聊天**：Netty + WebSocket、心跳、离线消息、消息可靠投递、在线状态

### 「萌宠奇遇」怎么用
把课程项目改造成有后端的样子：给现有需求补一套 **RESTful API + MySQL 表设计 + Redis 缓存**，写进简历。有真实业务背景的项目比纯 demo 可信。
